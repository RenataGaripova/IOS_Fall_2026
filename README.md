# Favorites Navigator — MovieApp
**Author:** Garipova Renata

**Theme:** Movies, Tv Shows

A simple UIKit app with a list of my favorite movies and TV Shows. Tapping a movie opens a detail screen
with its poster, year, authors, rating and description. Built with Storyboard and UINavigationController.
